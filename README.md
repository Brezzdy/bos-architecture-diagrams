# BOS Architecture Diagrams

Interactive architecture documentation for the **Business Operating System** platform.

Deployed automatically to GitHub Pages using [declarative-diagram-builder](https://github.com/Brezzdy/declarative-diagram-builder).

## Diagrams

| Diagram | Description |
|---------|-------------|
| Infrastructure Overview | High-level platform architecture |
| Client Provisioning Flow | New client VPS setup sequence |
| SSO Authentication Flow | Authentik OAuth2 flow |
| Deployment Pipeline | CI/CD workflow |
| Network Topology | Security layers and traffic flow |
| User Onboarding | New user provisioning process |

## Usage

Push to `main` → diagrams auto-deploy to GitHub Pages as interactive HTML with pan/zoom, dark mode, and search.
